AI vs ML vs Deep Learning

## Project Overview

This project explains and compares Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL), including their definitions, differences, relationship, and real-world examples.

## Objectives

- Understand AI, ML, and Deep Learning.
- Compare their scope and characteristics.
- Identify real-world applications.
- Explain how ML and DL relate to AI.

## Tools Used

- Google Colab
- Python

## Relationship

AI is the broadest field.

Machine Learning is a subset of AI.

Deep Learning is a subset of Machine Learning.

AI
└── Machine Learning
    └── Deep Learning

## Comparison

| Feature | AI | ML | Deep Learning |
|---|---|---|---|
| Meaning | Broad field of intelligent systems | Learning from data | Learning using multi-layer neural networks |
| Scope | Broadest | Subset of AI | Subset of ML |
| Examples | Virtual assistants, game AI | Spam/fraud detection, recommendations | Image/speech recognition |
